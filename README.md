## Run and debug

In IntelliJ IDEA, select the shared **Stefano JavaFX** Maven run configuration and
choose **Run** or **Debug**. It launches the application with the JavaFX runtime
provided by the `javafx-maven-plugin`; do not launch `sst.stefano.main.Stefano`
as a plain Java application, which omits the JavaFX runtime modules.

From a terminal, run `mvn javafx:run` from the project directory.
